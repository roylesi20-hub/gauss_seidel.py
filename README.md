
# Algoritma Penyelesaian SPL Metode Gauss-Seidel

## Deskripsi
Program Python untuk menyelesaikan Sistem Persamaan Linear (SPL)
menggunakan metode iterasi Gauss-Seidel.

## Teknologi
- Python
- NumPy

## Cara Menjalankan
1. Instal Python.
2. Instal NumPy dengan perintah:
   pip install numpy
3. Jalankan program:
   python gauss_seidel.py

## Contoh Hasil
Solusi sistem persamaan mendekati:
- x1 = 1
- x2 = 2
- x3 = -1
